VOREXA screenshot-based website

The supplied reference screenshots remain the visible page artwork. The duplicated added ticker, floating bottom navigation, and extra scanning overlay have been removed so they do not cover the original design. Invisible click areas are retained over selected screenshot buttons for section navigation. FAQ buttons show an answer; contact and FAQ forms open the visitor's email app (mailto) and do not send directly from a server.

Run locally: python -m http.server 8080, then open http://localhost:8080

To publish changes, upload the contents of this folder to your hosting provider. A local ZIP change does not automatically update an already-published Netlify site.
